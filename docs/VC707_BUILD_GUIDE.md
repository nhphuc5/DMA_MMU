# VC707 hardware target

## Exact target

- Board: AMD/Xilinx Virtex-7 FPGA VC707 Evaluation Kit
- FPGA: `XC7VX485T-2FFG1761C`
- Vivado part: `xc7vx485tffg1761-2`
- Board clock: differential LVDS 200 MHz
- SoC clock: 150 MHz, generated by `MMCME2_BASE`
- On-chip memory: existing 64-KiB AXI BRAM
- UART: board USB-UART at approximately 115200 baud

The VC707 DDR3 SODIMM is not used by this board target yet.  The project now
contains a custom AXI DDR3 digital controller and BRAM+DDR decoder, but the
Virtex-7 x64 pin PHY/calibration layer is intentionally not represented as
complete.  See `docs/CUSTOM_DDR3_CONTROLLER_GUIDE.md`; enabling the SODIMM is
a board-PHY extension, not a pin-only edit.

## Files

- `src/SoC/dma_mmu_picorv32_vc707_top.sv`: board clock/reset wrapper.
- `constraints/dma_mmu_picorv32_vc707.xdc`: VC707 clock, reset, UART and LED pins.
- `firmware/build/vc707/soc_demo.hex`: hardware UART firmware image.
- `scripts/create_vc707_project.tcl`: creates the VC707 Vivado project.
- `scripts/run_vc707_simulation.tcl`: runs all existing functional tests.
- `scripts/run_vc707_implementation.tcl`: creates reports and bitstream.

## One-click commands

1. Run `CHECK_VC707_SUPPORT.cmd`.
2. Run `RUN_VC707_SIMULATION.cmd` for the self-checking RTL regression.
3. Run `OPEN_VC707_PROJECT.cmd` to open the GUI project.
4. Run `BUILD_VC707_BITSTREAM.cmd` after installing a synthesis license that
   covers `XC7VX485T`.

To open the installed Vivado 2025.1 License Manager directly, run
`OPEN_VIVADO_LICENSE_MANAGER.cmd`.

Project file:

`build/vivado/vc707/DMA_IOMMU_PicoRV32_VC707.xpr`

Generated bitstream:

`bitstream/DMA_IOMMU_PicoRV32_VC707.bit`

## Device support versus license

Device support supplies the part database and board files.  A synthesis
license is a separate requirement for this Virtex-7 device.  The supplied
`vivado2018IPs.lic` was verified on 2026-08-17 with Vivado 2025.1: Vivado
successfully checked out both Synthesis and Implementation for `xc7vx485t`,
and the custom controller completed OOC route.  The license file itself is not
part of this repository.  See
`reports/ddr3_controller/VC707_VERIFICATION_SUMMARY.md` and the associated log.

This successful checkout does not change the board-level DDR status described
above.  The current VC707 top/XDC still have no SODIMM ports or DDR pin
constraints, and `ENABLE_DDR3` remains disabled by default.

On Vivado 2025.1, Virtex-7 is not included in the license-free ML Standard
device list.  Valid solutions are either:

1. Install a valid 2025.1 Enterprise/device-locked VC707 license using Vivado
   License Manager; or
2. Install Vivado 2026.1 and obtain the free annual BASIC license. AMD lists
   all 7-Series devices, including Virtex-7, under the 2026.1 BASIC tier.

The 2026.1 BASIC license does not grant use of older pre-2026.1 Vivado
versions, so it must be used with Vivado 2026.1 rather than the installed
2025.1 executable.

The VC707 `.cmd` launchers automatically prefer Vivado 2026.1 when it is
installed in a standard AMD/Xilinx location, then fall back to 2025.2 and
2025.1. You can also set the `VIVADO` environment variable to the full path
of `vivado.bat` before running a launcher.
